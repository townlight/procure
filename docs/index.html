Townlight / Townlight Procurement

Procurement packets that survive the audit.

Townlight Procurement v0.3.0 ships RFP drafting, proposal comparison, exception extraction, scoring summaries, award-packet checklists, optional database-backed workpapers, staff review queues, review-required context packets, adversarial local mocks, and an accessible sample UI.

Recovery v0.3.0

What ships

  • Sample RFP drafting.
  • Proposal comparison.
  • Exception extraction helper.
  • Scoring summary helper.
  • Award-packet checklist.
  • Optional RFP/award workpaper persistence.
  • Staff queue routes protected by TOWNLIGHT_PROCUREMENT_STAFF_API_KEY.
  • Review-required Townlight Meetings and Townlight Contracts context packets.
  • Adversarial local integration mocks.
  • Public sample UI at /townlight_procurement.

What does not ship

Townlight Procurement does not evaluate vendors, award contracts, make award decisions, submit procurements, provide legal advice, call live LLMs, use live vendor portals, or replace the procurement system of record.
